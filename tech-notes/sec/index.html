Security Flow

Most notes fit into this operating loop: identify actors, scope access, reduce blast radius, and watch for abuse.

Identify

Use SSO, OIDC, WebAuthn, mTLS, JWT validation, and agent identity to establish who or what is calling.

Authorize

Use RBAC, ABAC, policy engines, ReBAC, and fine-grained checks to answer what the caller may do.

Contain

Use zero trust, sandboxing, container controls, vaults, and short-lived credentials to limit damage.

Defend

Use threat analysis, WAFs, anti-bot controls, DNS privacy, and supply-chain guardrails to catch attacks earlier.

How To Read It

Use the page as a field guide: pick a system area, then follow the notes that explain the main choices and traps.

Build an access model

Human login
Start with WebAuthn, SSO/SAML, OAuth/OIDC, and JWT validation.
Service calls
Use mTLS, SPIFFE, short-lived tokens, and audience-bound JWTs.
Permissions
Choose RBAC for simple roles, ABAC for context, and ReBAC/FGA for object sharing.

Reduce attack impact

Runtime
Use sandboxing, container hardening, admission control, and runtime detection.
Secrets
Centralize secrets, rotate them, audit access, and remove long-lived credentials.
Exposure
Put WAF and anti-bot layers on public paths, then threat-model the gaps they cannot cover.
