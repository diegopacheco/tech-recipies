Bloom Filter

A bit array plus k hash functions. Insert flips k bits on; lookup checks them. Any 0 means definitely not present. All 1s means probably present — and sometimes that's a false positive. Watch the bits light up.

Event log

Bloom filter (Burton Bloom, 1970). False positive rate p ≈ (1 − e^(−kn/m))^k. Optimal k = (m/n)·ln 2. No false negatives, ever.
