Before the first response

Meet. Agree. Send.

A connection is a short negotiation before application data can flow. TCP synchronizes sequence spaces, TLS proves identity and establishes keys, while QUIC combines transport and security.

TCP flag anatomy

Three packets create shared certainty.

Both sides choose an initial sequence number, prove they can send and receive, and acknowledge the next byte expected. Reliability begins with that shared state.

SYN

Synchronize. The client proposes its starting sequence number and TCP options.

SYN + ACK

The server acknowledges the client and proposes its own starting sequence number.

ACK

The client acknowledges the server. The TCP connection is established.

FIN / RST

FIN closes gracefully in each direction. RST aborts the connection immediately.
