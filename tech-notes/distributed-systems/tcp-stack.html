Protocol field map

The packet’s long way down.

A request begins as meaning, becomes bytes, receives transport and network coordinates, then leaves as a signal. Seven conceptual layers make the handoffs visible.

Keep this distinction

HTTP, gRPC, and WebSocket describe conversations. TCP and UDP move their bytes. IP finds the destination.

    03 / Boundary cases

    The useful corrections

    Protocol diagrams are maps, not territory. These four relationships prevent the most common layer mix-ups.

    WebSocket

    Application layer, carried by TCP

    It begins as an HTTP Upgrade exchange, then switches to full-duplex WebSocket frames on the same TCP connection.

    gRPC

    RPC semantics over HTTP/2

    Protobuf messages become HTTP/2 frames, usually protected by TLS, then travel inside TCP segments.

    HTTP/3

    HTTP semantics without TCP

    HTTP/3 uses QUIC, which combines transport and TLS over UDP. Independent streams avoid TCP-wide loss stalls.

    Load balancing

    Layer number defines visibility

    An L4 balancer sees flows. An L7 balancer terminates or parses application traffic and can make content-aware routing decisions.
