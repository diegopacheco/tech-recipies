Application boundary

Spring Boot setup

Spring does not invent an isolation policy. With Isolation.DEFAULT, the transaction manager uses the connection’s database default: PostgreSQL gets Read Committed; MySQL/InnoDB gets Repeatable Read.

Recommended scope

Set the level on the smallest service method that needs it. A pool-wide setting changes every borrowed connection.

Boundary rule: an isolation setting applies when a new transaction starts. With REQUIRED, an existing outer transaction keeps its original level. Use REQUIRES_NEW only when a separate boundary is intentional.
